# Homelab

A self-hosted homelab built mostly from e-waste, for learning
systems and infrastructure engineering.

**Total cost: $250**

## Hardware

| Device | Specs | Role | Source |
|---|---|---|---|
| Mac Pro (Late 2013) | 3.7GHz 4-core Xeon E5, 16GB RAM, 1TB SSD, dual FirePro D300 | Proxmox hypervisor | Bought used, $250 |
| LaCie d2 | 4TB HDD | Backup storage | Rescued from e-waste |
| AirPort Express (A1392) | 802.11n | Wi-Fi to Ethernet bridge | Rescued from e-waste |

## Goals
- Learn Linux, virtualization, and networking hands-on
- Build an encrypted backup server for my laptop and phone photos
- Automate the setup so it can be rebuilt from scratch

## Roadmap
- [ ] Bridge Wi-Fi to Ethernet with the AirPort Express
- [ ] Install Proxmox VE on the Mac Pro
- [ ] Time Machine backups over the network (encrypted)
- [ ] Immich for photo backup
- [ ] Remote access with Tailscale
- [ ] Automate setup with Ansible
- [ ] Offsite backup copy
